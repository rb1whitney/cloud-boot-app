# Support

## How to get help

If you're having trouble with Cloud Boot App, there are several ways to get help:

### GitHub Issues

The [GitHub Issue tracker](https://github.comrb1whitneycloud-boot-app/issues) is the best place to report bugs or request new features.

### General Questions

For general questions, please use the [GitHub Discussions](https://github.comrb1whitneycloud-boot-app/discussions) if enabled, or check the documentation in the `docs/` folder.
